### The Mission

Build a **USI campus connector** that finds the **fewest links** from **Rice Library** to **Orr Center**. Buildings are vertices; fictional two-way connectors are unweighted edges. In a **connector group**, every building links directly to every other member.

### Part A: The Proof Detective (50 Points)

**Instructions:** Answer Questions 1–4 in a separate PDF or Markdown document, using matching numbers and our A–F class methods.

1. **Proof by Induction — BFS Layering:**

Prove by induction on layer d that BFS visits every vertex at graph-distance d before any at distance d + 1. State the **base case** (d = 0), assumption and step, and justify **FIFO layer order**. Review slides 23 and 30.

**The Brutality Clause:** Missing the explicit base case earns **0 on Question 1**, regardless of the inductive step.

2. **Visual Tracing — A Campus Route:**

Use labels **A = Rice Library, B = University Center, C = Liberal Arts Center, D = Science Center, E = Orr Center**. The groups are **Link 1: [****A,B****], Link 2: [****B,D****], Link 3: [****D,E****], Link 4: [****A,C****]**. Use full building names in code.

• Draw the graph. Start BFS at **A**, state your neighbor order, and record the initial **queue/visited set** and each subsequent state until **E is discovered**.

• Report the minimum number of links. Review slides 11–21 and 28–29.

3. **DFS Discovery and Finish Times — One New Connection:**

Add the **C–D** link. The edges are now A-B, A-C, B-D, C-D, D-E.

• Start DFS at **A**, visit labels alphabetically, and record every vertex's **discovery/finish ****times** with one clock.

• Explain cycle detection using your trace, timestamps or edge classification; distinguish a parent edge from cycle evidence. Review slides 39–53.

4. **PDC Reasoning — Two Workers and One Building:**

Two workers in the **same BFS frontier** check the **same unseen building** before either records discovery. Trace the interleaving and explain the duplicate queue entry or conflicting parent/distance update. Identify **atomic check-and-record operations**, then explain separately why they do not guarantee **BFS layer order**. No threaded code is required. See slides 64–65.
